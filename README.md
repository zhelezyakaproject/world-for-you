# Симуляция #1 — мир, который строит для вас ИИ

Готовая заготовка мира сделана для автора канала **@LinnikX** (Линник): все детали в ней — про него. Для вас агент подготовит каждый уровень заново.

Свежая версия, вопросы и ошибки — на GitHub: https://github.com/zhelezyakaproject/simulation-1 (ошибку — во вкладку Issues).

Вы надеваете VR-шлем или садитесь за компьютер и попадаете в мир, который для вас построил ИИ-агент (Claude Code). Шлем не обязателен: тот же мир работает с компьютера — мышь и клавиши. Агент говорит с вами голосом, слышит вас и управляет миром на ходу. Мир строится из того, что агент о вас знает: сначала вы знакомитесь, потом вы говорите, что должно быть на каждом уровне, и агент собирает свою версию — с деталями из вашего знакомства и со своим почерком.

Заготовка уже готова — три уровня:

1. **Разговор.** Как ИИ видит и ощущает пространство вокруг себя: лента текста вашего разговора, знания из слов, нити внимания, образы из огней сети, тело агента из слов. Здесь можно порассуждать, есть ли у ИИ осознание и своё «я».
2. **Мир для тебя.** Сейчас это мир, который один агент создал для Линника: остров в воде-зеркале, пёс три метра ростом, солнце можно взять рукой, лестница в небо, звездопад, дневник агента. Погулять можно, но это как смотреть чужой сон. После знакомства агент строит этот уровень заново — только для вас.
3. **Общая территория.** Гостиная — сейчас дом автора, после знакомства агент может построить ваш. Она превращается в игровой зал: боулинг и баскетбол против агента на честный ответ, фото на память, рубильник «выключить мир».

Если чего-то в мире нет, а вы просите, — агент запускает помощников, и они достраивают это во время встречи.

## Как начать

1. Поставьте всё из раздела «Установка» (или попросите агента — он поставит сам).
2. Откройте Claude Code в этой папке и напишите: «Привет, давай знакомиться». Агент расскажет, что дальше. Хотите сразу играть в заготовку — напишите «просто запускай».

Агента ведёт файл `CLAUDE.md`, справочник мира для него — `world/МИР.md`.

**Какой нужен агент.** Мир проверен с [Claude Code](https://claude.com/claude-code). Нужна подписка Claude Pro или Max: агент строит мир помощниками, и на Pro перестройка всего мира может упереться в лимит. Другой ИИ-агент, который умеет запускать команды на компьютере, тоже может вести мир по `CLAUDE.md`, но это не проверялось.

## Установка

Нужно: Windows 10/11 (на macOS и Linux работает режим монитора, шлем не проверялся), Google Chrome, [Node.js](https://nodejs.org) 18 или новее, [Claude Code](https://claude.com/claude-code). Для шлема нужна видеокарта NVIDIA; мир проверен на RTX 5060 Ti. С компьютера мир идёт и на слабом железе, распознавание речи работает и без видеокарты.

**Мир:**

```
cd world
npm install
```

**Распознавание речи** — модель GigaAM v3 от Сбера, Python 3.10–3.12. Из корня проекта:

```
python -m venv .venv
.venv\Scripts\pip install torch torchaudio --index-url https://download.pytorch.org/whl/cu128
.venv\Scripts\pip install git+https://github.com/salute-developers/GigaAM@7447938d791c4f3e643386ee22c33777004293a5 sentencepiece numpy
```

Какую сборку `torch` ставить во второй строке:

| Видеокарта | Конец второй строки |
|---|---|
| NVIDIA RTX 20, 30, 40, 50, GTX 16 (драйвер 570 или новее) | `whl/cu128` — для RTX 50 обязательно |
| NVIDIA GTX 10 или драйвер старее 570 | `whl/cu126` (или обновите драйвер). Речь падает с ошибкой «no kernel image» — `whl/cu118` |
| AMD, Intel, без видеокарты | вся строка — `.venv\Scripts\pip install torch torchaudio`: речь распознаётся на процессоре: 0,2–1 с на фразу | На macOS и Linux вместо `.venv\Scripts\` — `.venv/bin/`. Модель (около 430 МБ) скачается в `models/` при первом запуске мира. GigaAM — официальный репозиторий Сбера, лицензия MIT; в строке установки закреплена проверенная с миром версия (август 2026). Распознаванию нужно около 2 ГБ оперативной памяти (и 0,5 ГБ видеопамяти на NVIDIA). Не хотите ставить Python — в `world/config.json` поставьте `"stt": "none"` и пишите фразы текстом: клавиша `T` в окне мира.

**Голос агента** — [ElevenLabs](https://elevenlabs.io), бесплатного плана хватает на знакомство с миром. Создайте ключ API и положите его в файл `.env` в корне проекта:

```
ELEVENLABS_API_KEY=ваш_ключ
```

Голос выбирается в `world/config.json` → `voice.id` (агент поможет выбрать).

Без ключа агент говорит бесплатным голосом Microsoft Edge: ничего ставить не нужно, нужен интернет. Голос — `world/config.json` → `voice.edgeVoice` (по умолчанию `ru-RU-SvetlanaNeural`; русский мужской `ru-RU-DmitryNeural` сейчас не отвечает; мужской многоязычный — `en-US-AndrewMultilingualNeural`, на слух не проверен). Выбрать явно — `voice.provider`: `"elevenlabs"`, `"edge"` или `"none"` (без голоса).

**Проверка без шлема:** `node world/test/run.mjs` — в конце «провалено 0».

## VR-шлем

Мир открывается в Chrome через WebXR. Шлем должен быть виден компьютеру через SteamVR:

1. Поставьте [SteamVR](https://store.steampowered.com/app/250820/SteamVR/).
2. Подключите шлем к компьютеру: Quest — Quest Link, Air Link или Steam Link; Pico — PICO Connect; другие шлемы для ПК — их программа.
3. SteamVR → Настройки → OpenXR → «Сделать SteamVR средой выполнения OpenXR».
4. SteamVR → Настройки → Видео: частота 90 Гц, разрешение рендеринга — вручную, около 1900×1900 на глаз. Картинка дёргается — уменьшите разрешение или поставьте `client.xr.scale: 0.8` в `world/config.json`; крайний случай — `"quality": "lite"`.
5. Запустите мир и в окне Chrome нажмите «Войти в мир».

Звук агента должен идти в наушники или динамики шлема, а не в колонки компьютера: иначе микрофон слышит агента (эхо). Нужный микрофон можно задать по имени: `world/config.json` → `client.mic.device` (часть названия из Windows).

Запасной путь без SteamVR — открыть мир в браузере самого шлема по Wi-Fi. Для этого нужен сертификат:

```
openssl req -x509 -newkey rsa:2048 -nodes -keyout world/cert/key.pem -out world/cert/cert.pem -days 365 -subj "/CN=world-for-you"
```

После запуска окно сервера покажет адрес вида `https://192.168.x.x:8443`. Откройте его в браузере шлема, на предупреждении о сертификате — «Дополнительно» → «Перейти». Картинку тогда считает сам шлем, качество упрощается.

## Запуск

Агент запускает мир сам. Вручную (Windows) — дважды щёлкнуть `world/Запуск мира — шлем.bat` или `world/Запуск мира — компьютер.bat`. Из командной строки: `OPEN=1 node world/server.mjs` (шлем) или `OPEN=1 PC=1 node world/server.mjs` (компьютер — режим монитора, даже если шлем подключён). Через 5 секунд откроется отдельное окно Chrome со своим профилем (папка `world/.chrome`). В первый раз Chrome спросит разрешение на микрофон и на шлем — разрешите. Окно во время встречи не сворачивайте.

Остановить: агент делает `node world/fable.mjs quit`; вручную — закрыть окно сервера.

Пока мир запущен, агент слушает вас и не отвечает в чате — это нормально: встреча идёт голосом. Чтобы написать ему в чат, нажмите Esc в Claude Code.

## Управление

| В шлеме | Что делает |
|---|---|
| Левый стик | идти туда, куда смотришь |
| Правый стик влево/вправо | поворот на 30° |
| Боковая кнопка (хват) | взять предмет рядом; издалека — направить руку на предмет и сжать, он прилетит в руку |
| Курок | листать дневник, когда он в руке; навести руку на вариант развилки или на строку ленты и нажать — выбрать вариант, тронуть строку |
| Дотронуться рукой | вариант развилки перед собой; старая строка ленты в локации 1; слово рядом со знанием |
| Навести руку на солнце + хват | взять солнце и вести его по небу |

На мониторе: мышь — смотреть, `WASD` — идти, ПКМ — хват, ЛКМ — курок, `1` `2` `3` — локации, `V` — вид камеры, `R` — запись, `T` — фраза текстом вместо голоса.

## Если что-то сломалось

| Что случилось | Что делать |
|---|---|
| Страницу мира перезагрузили или вкладка упала | Мир откроется в той же локации. Снова нажать «Войти в мир». Вещи, которые агент достроил на ходу, он отправит заново |
| Окно сервера закрыли или сервер упал | Запустить мир снова. Открытая вкладка подключится сама за 3–5 с. Распознавание речи грузится около 10 с |
| Агент не слышит | Проверить микрофон: в Chrome разрешён, нужный выбран (`client.mic.device`); порог громкости — `client.mic.threshold` |
| Агент отвечает сам себе | Это эхо: звук агента — в наушники или шлем; поднять `client.mic.threshold` до 0.03–0.05 |
| Кнопка контроллера не та | Сказать агенту: он посмотрит, что приходит с контроллеров, и переназначит кнопку |

## Что пишется на диск

`media/session/<дата-время>/`: `log.jsonl` (всё по времени: фразы, ответы, события), `guest/` (ваши фразы, звук), `fable/` (голос агента и текст реплик), `frames/` (кадры глаз агента). Если включена запись камер — `rec/views-*.mp4` и `rec/sound-*.webm`; склейка в один файл — `node world/tools/join-rec.mjs <папка rec>` (нужен ffmpeg). Всё это остаётся на вашем компьютере; папки `media/session/` и `знакомство/` не попадают в Git.

## Проверки

```
node world/tools/check.mjs         # перед игрой: всё ли стоит — речь, голос, микрофон, Chrome (около 30 с)
node world/test/run.mjs            # все локации, автопроверки, кадры в media/shots
node world/test/actions.mjs        # пульт агента: все действия и неверный ввод
node world/test/shot.mjs 2 имя "W.locs[2].hero()"   # кадр по заказу
node world/test/perf.mjs           # время кадра «как в шлеме»
node world/test/perf.mjs --pc      # время кадра с компьютера (--cpu 3 — процессор в 3 раза медленнее)
node world/test/run.mjs --emu      # вход в шлем через эмулятор
```

## Карта файлов

| Файл | Что в нём |
|---|---|
| `CLAUDE.md` | инструкция агента: подготовка, знакомство, своя версия мира, встреча |
| `world/МИР.md` | справочник агента: пульт, все действия, сценарий трёх уровней |
| `world/server.mjs` | сервер: страница, связь мира с агентом, распознавание речи, голос (ElevenLabs или Edge), запись |
| `world/fable.mjs` | пульт агента: слушать, говорить, действовать, дописывать мир |
| `world/config.json` | настройки: имена, голос, микрофон, качество, камеры записи, кнопки |
| `world/src/` | сам мир: `main.js` — сборка и цикл, `loc1–3.js` — уровни, остальное — их части |
| `world/live/` | вещи, которые агент достраивает во время встречи |
| `world/stt_gigaam.py` · `stt.py` | распознавание речи: GigaAM (по умолчанию) и Whisper (`"stt": "whisper"`, нужна NVIDIA) |
| `media/` | модели и небо; лицензии и авторы — `media/ASSETS.md` |
